# wearexnetwork.co.uk — draft only

Private draft of the X Network Ltd site for small businesses.
The offer is a team — Dave (construction director) and Grok Bot (the AI) — as an outsourced back office. 24/7 service with us. Not a training course, and not software.
Sells the result: clearer quotes, organised enquiries, less paperwork.
Construction firms are the starting point. Kept separate from the construction website (xnetworkltd.co.uk).

**Do not publish. Do not enable GitHub Pages. Do not point DNS. Do not make this repository public.**
